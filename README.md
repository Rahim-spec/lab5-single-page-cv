# lab5-single-page-cv

# prompts

Create a sleek, dark-themed single-page CV web application with a strictly vertical-only layout. Use a rich charcoal/black background (#111318) with subtle dark container cards (#1A1D24) and crisp white and silver typography for a clean, modern aesthetic.

Structure the page with the following vertical sections in order:

1. **Header / Personal Profile**:
- A prominent side-by-side card at the top featuring a clean headshot photo on the left.
- On the right, display the full name "ALEX MERCER" in bold, high-contrast all-caps, followed by the title "Full Stack Developer / Designer".
- Below the title, include a compact metadata list for Age, Phone, Email, and Location with subtle grey icons.

2. **'About' & 'Education' Section**:
- Combine short intro summary text with a vertical timeline for education.
- Display entries clearly (e.g., "B.Sc. in Computer Science" and "B.Sc. Company Shani") with subtle white node icons and light grey institution details.

3. **Skills Section**:
- Present technical skills using dark rounded pill tags with clear white labels (e.g., UI/UX Design, JavaScript, Project Management, Python, Skills).
- Arrange them in a clean 3-to-4 column grid layout with generous gap spacing.

4. **Hobbies Section**:
- Display hobbies in a horizontal row of minimalist dark card tiles (Photography 📷, Travel ✈️, Chess ♟️, Reading 📚).
- Center-align the line-art icons and titles on each tile.

5. **Certificates Section**:
- A prominent grid layout displaying certificate credential cards (e.g., Google UX Design, AWS Certified Cloud Practitioner).
- Each card should feature a high-contrast white image placeholder thumbnail at the top, credential title in bold below, and a sleek outline "View" action button at the bottom.

Ensure strict single-page vertical scrolling, sans-serif typography, generous section padding, and subtle subtle border contrast between dark containers.
